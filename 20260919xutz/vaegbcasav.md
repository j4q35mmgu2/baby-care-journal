# 为什么十年前后悔给孩子打生长激素了？

> 更新时间：2026-09-19 (UTC+8)

我儿子今年4岁，身高99.6cm，体重15公斤。发现他比同龄孩子矮小，我怕孩子以后长不高。然后前几天带他到医院去检测了生长发育，医生拍片做了骨龄、脑垂体核磁共振、血液微量元素等检查，初步诊断为矮小症。然后建议我们给孩子打生长激素，我和老公现在很纠结，该不该打。因为我一个朋友说她老家有个孩子十年前打过生长激素，然后也没有长多高，现在说都后悔了。我们还是怕影响孩子将来身高，所以想问问为什么十年前后悔给孩子打生长激素了？除了并没长多高还有什么危害吗？ 
查看全部内容

后悔给孩子打生长激素一方面可能是因为在孩子骨骺闭合或接近闭合时，使用生长激素后，发现无效或者是效果不明显。另一方面就是可能导致出现一些副作用，比如说出现甲状腺低减的症状，或者是在打生长激素后，出现轻微的头痛现象。导致孩子矮小的原因有很多，也很复杂，打生长激素也不是对任何病因、任何时期的矮小儿童都有效的。

儿童生长受阻出现身材矮小等症状的，只要骨骺没有完全闭合，且孩子的各项检查都合格，那么使用生长激素治疗身材矮小就是有效的，也是安全的。反之，使用生长激素的话，就可能会发生一些副作用，如下：

- 1. 可能引起人体产生对生长激素的抗体反应，从而影响内源性生长激素的活性及导致激素分泌紊乱；
- 2. 如果是过了发育期，长骨的骨骺已经闭合，出现生长素的分泌增加，或者是额外注射生长素，则可以导致肢端肥大症；
- 3. 人体有反馈机制调节，生长激素的过量使用使得自身原本分泌的生长激素水平下降；
- 4. 在使用生长激素治疗的头几个月时间里，患者可能会出现头痛，呕吐，视力丧失等现象，这就是副作用导致的颅内压增高现象；
- 5. 大部分患者在注射生长激素后，甲状腺功能不会有明显变化，但是有一部分患者在治疗后，甲状腺分泌会低于正常值，因此在注射生长激素期间，每三个月应该检测一下甲状腺功能；
- 6. 打完生长激素后，患者会出现轻度短暂的水钠滞留，就会引起高血糖和高血压，特别是有糖尿病家族史的，更要注意这个问题。

因此，在给孩子打生长激素的时候，一定要先检查好身体各方面的情况，在适合的状态下使用才是安全的，才不会后悔。
